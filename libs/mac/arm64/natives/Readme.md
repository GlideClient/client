# what is this?
By default, Minecraft 1.8.9 does run on apple silicone without rossetta which can cause issues if you use a native AS java version. <br>
These patches allow native execution of Glide within the development environment <br>

These were copied from the PrismLauncher macOS arm64 compatibility patches, see below:


- https://github.com/PrismLauncher/meta-launcher/blob/master/org.lwjgl/2.9.4-nightly-20150209.json
- https://github.com/MinecraftMachina/lwjgl/releases/download/2.9.4-20150209-mmachina.2/lwjgl-platform-2.9.4-nightly-20150209-natives-osx.jar
